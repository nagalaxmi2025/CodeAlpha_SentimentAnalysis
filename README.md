# CodeAlpha Sentiment Analysis

## Project Overview
This project performs sentiment analysis on customer reviews using Python and TextBlob.

## Technologies Used
- Python
- Pandas
- TextBlob
- Matplotlib

## Features
- Classifies reviews as Positive, Negative, or Neutral
- Visualizes sentiment distribution using a bar chart

## Output
The project analyzes customer reviews and displays sentiment results graphically.
